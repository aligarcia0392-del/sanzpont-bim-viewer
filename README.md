# Sanzpont BIM Viewer

Visor 3D de modelos IFC con cuantificación, cortes (Slice Z y section box), aislamiento por categoría y proyectos privados por usuario.

- **Sitio:** https://aligarcia0392-del.github.io/sanzpont-bim-viewer/
- `index.html` — inicio de sesión, lista de proyectos y compartir.
- `viewer.html` — visor 3D. Carga el paquete del proyecto desde Supabase (almacenamiento privado).
- Este repositorio solo contiene el programa del visor. **Ningún modelo se guarda aquí**: los proyectos son privados por defecto y viven en Supabase con reglas de acceso por usuario.
